# NETWORKWALKS-B084-WK2-PM1-PENETRATION-TESTING-FOOTPRINTING-
A hands-on penetration testing project focused on footprinting and reconnaissance using WHOIS, WhatWeb, NSLOOKUP, DNSRecon, cURL, and WAFW00F to gather domain information, identify web technologies, analyze DNS records, inspect HTTP headers, and detect Web Application Firewalls using Kali Linux.
